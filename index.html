how it works

There is no start. There is no stop.

Opening a socket is the only signal — so any tool wakes a sandbox without knowing sbx exists, and a few idle minutes sleep it back to zero.

01

Create it

One command realises the spec — a real Postgres, Redis or browser. --template works with nothing on disk.

02

Forget it

Ignore it and it sleeps to 0 B — a stopped container, volume intact. You never turn it off.

03

Connect

psql, a pool, Playwright or a test runner opens a socket and it's back in a second. You never turn it on.
