Scale-to-Zero Dev Infrastructure

Scale to zero for your whole dev stack.

Give every branch, task or agent a real Postgres, Redis or browser — on your laptop, a VM or a Kubernetes cluster, and drive them all from one CLI. Awake on connect, asleep at 0 B.

Get started Read the docs
my-branch — sbx
$ sbx create my-branch --template postgres
$ eval "$(sbx env my-branch)"
$ psql -U app -d app   # ← this wakes it
app=# served in ~1s. no start command. no compose.
# deployed to a VM or cluster? drive it all from the CLI:
$ sbx ui --connect https://sbx.example.dev
