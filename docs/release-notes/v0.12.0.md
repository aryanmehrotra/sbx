# sbx v0.12.0 — OpenSandbox API on Firecracker microVMs (not yet for untrusted code)

Released 2026-09-26.

`sbx serve --provider firecracker --osb-addr …` serves the OpenSandbox API with every sandbox
running as a microVM. SDKs, endpoints and the upstream conformance suite are the same as on
docker. **Warning:** the VMM runs as unconfined root here. Do not use it for untrusted code.

## Before you upgrade

- Warning: there is no jailer in this release, so the Firecracker VMM runs as unconfined root.
  Do this: use microVM API sandboxes only for trusted code, or upgrade to v0.13.0.
- New requirement: microVM guests are filtered per bridge. Do this: run `sbx doctor`, which
  checks `/dev/kvm`, iptables and each bridge guard.
- Nothing changes for docker or Kubernetes, or for API servers already running on docker.

## Highlights

```sh
sbx doctor
sbx serve --provider firecracker --osb-addr 127.0.0.1:8090
```

- Upstream conformance on microVMs in CI: 48 passed, 0 failed, 4 skipped (docker: 50, 0, 2).
- Code-interpreter images work. A sandbox is `Running` once Jupyter answers (3 min limit).
- A `pvc` volume is an ext4 block drive. Host-path volumes are refused by name.
- Snapshots are disk-only for API sandboxes.
- Each bridge has its own egress filter. By default it refuses private ranges and the host's own subnets.
- The bridge guard drops guest traffic before docker's port forwarding, and is re-checked on every wake.
- A Failed sandbox always says why, in its status, the daemon log and the history.

## Fixes

- Over vsock, only the first request on a keep-alive connection worked, breaking Jupyter readiness.
- `/etc/hosts` inside a VM now has `localhost` and the hostname, as in docker.

## Known limitations

- Unconfined VMM (see "Before you upgrade"). Fixed in v0.13.0.
- `--osb-pool` is refused with the firecracker provider.
- Without reflink, each VM copies its image's data: about 16 s for a 7.4 GiB image in CI.
  XFS with `reflink=1` or btrfs clones instantly.
- No bare-metal benchmark: [BENCHMARKS.md](https://github.com/aryanmehrotra/sbx/blob/v0.12.0/docs/BENCHMARKS.md).

## Upgrade

```sh
brew upgrade sbx                  # first install: brew install aryanmehrotra/tap/sbx
curl -fsSL https://raw.githubusercontent.com/aryanmehrotra/sbx/main/scripts/install.sh | VERSION=v0.12.0 sh
go install github.com/aryanmehrotra/sbx@v0.12.0
sbx doctor
```

Binaries for macOS, Linux, FreeBSD and Windows (amd64, arm64) are attached with `SHA256SUMS`.
Cluster activator: `ghcr.io/aryanmehrotra/sbx-activator:v0.12.0`.
