# sbx v0.7.0 — sandboxes for AI agents: egress allow-list, checkpoint/resume, `sbx with`

Released 2026-08-21.

A sandbox can now reach only the hosts you list, stay awake while an agent works inside it, and
save and restore its running processes. `sbx with` runs a command against a throwaway sandbox
and always cleans up. Everything here is opt-in.

## Highlights

```sh
sbx with test-db --template postgres -- go test ./...   # removed afterwards, even on failure
sbx checkpoint agent-42 mid-thought                     # dump memory and processes with CRIU
sbx resume     agent-42 mid-thought                     # restore them as they were
```

- `"egress_allow": ["api.openai.com", "pypi.org"]` lets a service reach only those hosts and
  their subdomains. The sandbox has no route out except a filtering proxy, injected as `HTTP_PROXY`/`HTTPS_PROXY`.
- `openai.com` allows `api.openai.com` and denies `openai.com.evil.com`. Do not combine it with `egress: "deny"`.
- `"idle": "never"` (or `"0"`) keeps a service awake until you sleep or remove it. `"30m"` sets a longer window.
- `sbx with` passes your command's exit status through, so CI gates on it. `--keep` leaves the sandbox.
- A checkpointed redis with persistence off keeps its in-memory keys across `sbx resume`.
  Measurement: [DECISIONS.md](https://github.com/aryanmehrotra/sbx/blob/v0.7.0/docs/DECISIONS.md).
- `sbx sleep` and `sbx wake` park a sandbox or bring it back now.
- A preview URL per pull request, self-hosted:
  [examples/pr-preview](https://github.com/aryanmehrotra/sbx/blob/v0.7.0/examples/pr-preview/README.md).
- The proxy relay buffer is 64 KiB, about 6.8 GB/s on loopback.

## Known limitations

- `egress_allow` needs a Linux host in this release. It is refused elsewhere, with a reason.
- `checkpoint` and `resume` need CRIU on a Linux host with podman. docker's own restore fails
  (two upstream bugs), so sbx routes through podman. On macOS it is refused.
- Stronger isolation needs a Linux host with the matching runtime. Each option refuses where it cannot run.

## Upgrade

```sh
brew upgrade sbx                  # first install: brew install aryanmehrotra/tap/sbx
curl -fsSL https://raw.githubusercontent.com/aryanmehrotra/sbx/main/scripts/install.sh | VERSION=v0.7.0 sh
go install github.com/aryanmehrotra/sbx@v0.7.0
sbx doctor
```

Binaries for macOS, Linux, FreeBSD and Windows (amd64, arm64) are attached with `SHA256SUMS`.
Cluster activator: `ghcr.io/aryanmehrotra/sbx-activator:v0.7.0`.
