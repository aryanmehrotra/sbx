# sbx v0.5.0 — configurable health-check interval (`health_interval`) and a readable `sbx ui` table

Released 2026-08-18.

You can now choose how often sbx health-checks your services, for the whole sandbox or per
service, so large sandboxes no longer run dozens of probe commands a second. `sbx ui` columns
line up whatever your names are, and CPU is shown in millicores.

## Before you upgrade

- Behaviour change: `sbx ui` shows CPU in millicores (`147mc`), not percent (`14.7%`), so it adds
  up and compares with a `500m` limit. Do this: nothing. Read `1000mc` as one full core.
- `health_interval` is optional. A spec without it behaves as in v0.4.0.

## Highlights

```json
{ "version": 1,
  "health_interval": "1s",
  "services": { "db": { "image": "postgres:16-alpine", "ports": [5432],
                        "health": "pg_isready -U app", "health_interval": "300ms" } } }
```

- Set `health_interval` for the sandbox, and override it on a service. The default is 300 ms.
- The interval is also the floor on how long a wake appears to take.
  [SPEC.md](https://github.com/aryanmehrotra/sbx/blob/v0.5.0/docs/SPEC.md) says which way to move it.
- Allowed range is 50 ms to 5 m. On Kubernetes, sub-second values round up to one second.
- `sbx ui` sizes every column from its contents and truncates nothing.
- Traces are coloured relative to the service's own peak when it has no limit.
- Every address is a clickable link in terminals that support it. It assumes `http://`.

## Fixes

- A sandbox of ten or more services pushed its row's CPU, memory and limit cells out of line.
- Opening the system pane (`a`) could leave the sandbox block empty.
- A line wider than the terminal made the dashboard scroll into stacked copies of its header.
- Rows looked one character out in iTerm2 and others, because a dash was drawn double-width.

## Known limitations

- A container shares the host kernel. `--isolation gvisor|kata` is refused where that runtime is absent.

## Upgrade

```sh
brew upgrade sbx                  # first install: brew install aryanmehrotra/tap/sbx
curl -fsSL https://raw.githubusercontent.com/aryanmehrotra/sbx/main/scripts/install.sh | VERSION=v0.5.0 sh
go install github.com/aryanmehrotra/sbx@v0.5.0
sbx doctor
```

Binaries for macOS, Linux, FreeBSD and Windows (amd64, arm64) are attached with `SHA256SUMS`.
Cluster activator: `ghcr.io/aryanmehrotra/sbx-activator:v0.5.0`.

Full changelog: https://github.com/aryanmehrotra/sbx/compare/v0.4.0...v0.5.0
