# sbx v0.2.0 — live dashboard (`sbx ui`), guided `sbx init`, Homebrew install

Released 2026-08-16.

v0.2.0 adds `sbx ui`, a live dashboard of every sandbox, and a guided `sbx init` for when you have
none yet. It also adds `sbx history` and a Homebrew install.

## Highlights

- See every sandbox with its state, CPU and memory, refreshed every second: `sbx ui`.
  Arrows move, `enter` wakes, `s` sleeps, `l` reads logs, `d` removes, `q` quits.
- An asleep service shows a dash, not a zero. With no terminal, `sbx ui` prints the table once.
- The update notice is checked in the background at most once a day, never in CI. `SBX_NO_UPDATE_CHECK=1` turns it off.
- Pick a template and get a `sandbox.json` written for you: `sbx init`. `sbx init > sandbox.json` still works in scripts.
- See every change, wake and sleep, with secrets redacted, even when docker is down: `sbx history`.
- `sbx <command> --help` explains one command on stdout. Errors name the next step.
- Install with Homebrew: `brew install aryanmehrotra/tap/sbx`. Release binaries rebuild bit for bit (Go 1.26.5 pinned).

## Fixes

- With docker unreachable, the dashboard no longer shows "no sandboxes yet" beside the error.
- The daemon's log output no longer has a ragged left edge.

## Known limitations

- Windows has no raw terminal mode here, so `sbx ui` prints the table once and says so.
- These notes were backfilled from the commits after the release.

## Upgrade

```sh
brew upgrade sbx                  # first install: brew install aryanmehrotra/tap/sbx
curl -fsSL https://raw.githubusercontent.com/aryanmehrotra/sbx/main/scripts/install.sh | VERSION=v0.2.0 sh
go install github.com/aryanmehrotra/sbx@v0.2.0
sbx doctor
```

Binaries for macOS, Linux, FreeBSD and Windows (amd64, arm64) are attached with `SHA256SUMS`.
Cluster activator: `ghcr.io/aryanmehrotra/sbx-activator:v0.2.0`.
