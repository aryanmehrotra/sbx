# sbx v0.6.0 — manage remote sandboxes from `sbx ui --connect`

Released 2026-08-18.

`sbx ui` can now show and control sandboxes deployed elsewhere, with the same dashboard, keys and
traces as locally. `f` forwards a remote service's ports to `127.0.0.1`. A deployment with no
container runtime still reports its own CPU and memory.

## Before you upgrade

- Behaviour change (security): a connect token now controls a deployment through the dashboard
  (wake, sleep, limit, remove, logs), not only reads it. Do this: treat `SBX_CONNECT_TOKEN` as a
  full credential, and point the dashboard only at deployments you trust.
- A local `sbx ui` and a plain `sbx connect` are unchanged.

## Highlights

```sh
sbx ui --connect https://sbx.example.dev
sbx ui --connect db=https://db.example.dev --connect cache=https://cache.example.dev
```

- It takes the same URLs and tokens as `sbx connect`. Several deployments merge into one screen.
- `enter` wakes, `s` sleeps, `L` limits, `d` removes and `l` reads logs, on the remote sandbox.
- `f` forwards the selected service's ports to `127.0.0.1` until you quit, so `psql` reaches it.
- A deployment with no container runtime reads its own cgroup (v1 and v2) for CPU, memory and limits.
  Where those files are missing it reports nothing rather than a zero.

## Fixes

- Over `--connect`, the title no longer shows your laptop's memory as the deployment host's.

## Known limitations

- A shell into a remote service (`exec`, a TTY, file copy) is refused over connect, with a message naming where it works.
- A container shares the host kernel. `--isolation gvisor|kata` is refused where that runtime is absent.

## Upgrade

```sh
brew upgrade sbx                  # first install: brew install aryanmehrotra/tap/sbx
curl -fsSL https://raw.githubusercontent.com/aryanmehrotra/sbx/main/scripts/install.sh | VERSION=v0.6.0 sh
go install github.com/aryanmehrotra/sbx@v0.6.0
sbx doctor
```

Binaries for macOS, Linux, FreeBSD and Windows (amd64, arm64) are attached with `SHA256SUMS`.
Cluster activator: `ghcr.io/aryanmehrotra/sbx-activator:v0.6.0`.
