# sbx v0.13.2 — OpenSandbox SDK pools and e2e tests now pass against sbx

Released 2026-09-27.

Upgrade if you drive sbx through the OpenSandbox SDKs. Upstream's `pool` and `e2e` test files
now pass and are gated in CI. Nothing changes for `sandbox.json`, the wake path, docker,
Kubernetes or the microVM provider.

v0.13.1 was tagged but never published. v0.13.2 is v0.13.1 plus a flaky-test fix; no product code differs.

## Before you upgrade

- Behaviour change: a code-interpreter sandbox reports `Running` once the in-sandbox agent
  answers, before Jupyter does. Do this: nothing with the SDK. A direct `/code` call waits for Jupyter.
- Behaviour change: `renew-expiration` to an earlier future time now succeeds and shortens the
  sandbox's life. Do this: only renew to the expiry you want. Now or the past is still a `400`.

## Highlights

- Upstream `pool` tests: 20 passed, gated in CI (4 passed, 8 failed before). `e2e`: 3 passed, gated.
- Why `Running` means the agent answers:
  [DECISIONS.md](https://github.com/aryanmehrotra/sbx/blob/v0.13.2/docs/DECISIONS.md) ("Running means usable").
- `501` errors name the missing feature and point to the roadmap, instead of promising v0.11.0.
- [COMPARISON.md](https://github.com/aryanmehrotra/sbx/blob/v0.13.2/docs/COMPARISON.md) adds agent sandboxes, each vendor figure linked.
- [BENCHMARKS.md](https://github.com/aryanmehrotra/sbx/blob/v0.13.2/docs/BENCHMARKS.md) adds the v0.13.0 microVM create figures.

## Fixes

- `scripts/osb-conformance.sh --no-key` always started the daemon with a key, so upstream's `e2e` file never ran.

## Known limitations

- Not built: `isolated_session` (48 tests) and `credential_vault` (4 tests).
  See [ROADMAP.md](https://github.com/aryanmehrotra/sbx/blob/v0.13.2/docs/ROADMAP.md).

## Upgrade

```sh
brew upgrade sbx                  # first install: brew install aryanmehrotra/tap/sbx
curl -fsSL https://raw.githubusercontent.com/aryanmehrotra/sbx/main/scripts/install.sh | VERSION=v0.13.2 sh
go install github.com/aryanmehrotra/sbx@v0.13.2
sbx doctor
```

Binaries for macOS, Linux, FreeBSD and Windows (amd64, arm64) are attached with `SHA256SUMS`.
Cluster activator: `ghcr.io/aryanmehrotra/sbx-activator:v0.13.2`.
